# Wine Quality Prediction

# Overview
This project explores various machine learning regression techniques to predict the quality of red wines based on their physicochemical features. The aim is to compare multiple models and identify the one that best predicts wine quality using key performance metrics.

# Dataset
The dataset used is winequality-red.csv, containing various chemical properties of red wine samples along with quality ratings on a scale of 0 to 10.

# Models Implemented
The following regression models are explored:

Linear Regression
Multiple Linear Regression
Decision Tree Regressor
Support Vector Regression (SVR)
Multi-Layer Perceptron (MLP) Regressor

# Evaluation Metrics
The models are evaluated using:

Mean Absolute Error (MAE)
Root Mean Squared Error (RMSE)
R² Score

# Project Structure
Data loading and preprocessing
Exploratory Data Analysis (EDA)
Model training and hyperparameter tuning
Model evaluation and comparison
Conclusion on model performance

# Libraries Used
pandas, numpy
matplotlib, seaborn
scikit-learn
statsmodels

# How to Run
Open the notebook in Google Colab.
Mount Google Drive and ensure the dataset path is correctly set.
Run the cells sequentially for data loading, model training, and evaluation.
